# Hololive Dreams Auto Jump Rope — 1.0

[繁體中文](README.md) · [简体中文](README.zh-CN.md) · [English](README.en.md) · [日本語](README.ja.md) · [한국어](README.ko.md) · [Indonesian](README.id.md)

Windows 版『hololive Dreams』の自動なわとびプログラムです。ゲーム画面から縄の位置を認識し、通常のマウス入力でジャンプを操作します。結果画面の確認後は次のプレイへ進みます。

## ダウンロード

[GitHub Releases](https://github.com/harrykuang-dev/Hololive-Dreams-Jump-Rope-Auto/releases/tag/v1.0) から `HololiveDreamsJumpRopeAuto-1.0.exe` をダウンロードしてください。

この EXE 一つで実行でき、Python のインストールは不要です。SHA-256 チェックサムも付属します。ソース ZIP を使う場合は自分でビルドしてください。

## 機能

- 縄の動きを追跡し、ジャンプのタイミングを自動判定します。
- 開始・結果画面のメニューを認識し、プレイ終了後に続行します。
- 繁体字中国語、簡体字中国語、英語、日本語、韓国語、インドネシア語の六つの表示言語に対応します。プログラムの言語変更はゲーム設定を変更しません。
- 目標回数を設定でき、到達すると停止します。開始するたびに集計をリセットします。
- 初期ショートカットは開始 F8、停止 F9 です。設定欄をクリックしてキーやキーの組み合わせを押すと変更できます。開始と停止には異なるキーを設定してください。
- 実行履歴と、任意で有効にできるローカル診断モードを備えています。

## 使い方

1. ゲームでなわとびの開始画面または結果画面を開きます。
2. EXE を実行し、「言語/Language」で表示言語を選びます。
3. 目標回数を 1–999 回に設定します。初期値は 1 回です。ショートカットを変更する場合は設定欄をクリックして希望のキーを押します。
4. 開始ボタンまたは開始ショートカットを押します。プログラムはゲームを前面に切り替えようとします。ゲーム全体をメインモニター内に表示し、ほかのウィンドウで隠さないでください。暗い色で短髪、装飾やアクセサリーの少ないキャラクターがおすすめです。例：**儒烏風亭らでん（デフォルト衣装）**とピクセルサングラス（pixel sunglasses）。
5. 停止ショートカット、停止ボタン、または別のウィンドウへの切り替えで停止します。再開すると集計をリセットします。

## 動作条件と制限

Windows 10／11 x64 と Windows 版ゲームが必要です。ゲームのクライアント領域を 16:9 に保ち、動作中に最小化・遮蔽・移動しないでください。バックグラウンドでのプレイや、日付更新によるログアウト後の自動ログインには対応しません。

ゲームが安定して 60 FPS を維持できる範囲で、画質設定をできるだけ高くしてください。

画面の「ジャンプ入力」は入力回数です。実際の得点はゲームの結果画面で確認してください。キャラクターの色、アニメーション、解像度、PC の性能やゲーム更新が認識に影響する場合があります。問題が起きたら停止し、診断データを提供してください。

> [!WARNING]
> **デュアル GPU 環境での画面取得エラー**
>
> 開始時に `-2005270524 / 0x887A0004`（指定されたデバイス インターフェイスまたは機能レベルは、このシステムではサポートされていません。）が表示された場合は、プログラムの GPU 設定を変更してください。
>
> ![DXGI の画面取得エラー](docs/dxgi-unsupported-error.png)
>
> 1. Windows の「設定 → システム → ディスプレイ → ディスプレイの詳細設定」でゲームに使用するメインモニターを選び、表示される接続先 GPU の名前を確認します。
> 2. 「ディスプレイ → グラフィックス」（Windows 10 では「グラフィックス設定」）に戻り、デスクトップアプリを追加して、実際に使用する `HololiveDreamsJumpRopeAuto-1.0.exe` を選びます。
> 3. アプリの「オプション」を開き、「グラフィックの環境設定」で上記の GPU を選択して「保存」を押します。「省電力」は通常内蔵 GPU、「高パフォーマンス」は通常独立 GPU です。表示される GPU 名で確認してください。
> 4. プログラムを完全に終了して再起動し、「開始」で確認します。
>
> 設定対象はプログラムの EXE です。内蔵画面と外部モニター、独立 GPU 直結モードとハイブリッドモードでは、画面出力を担当する GPU が異なる場合があります。現在の接続先に合わせて選択してください。解決しない場合は開発者モードで一度再現し、その実行フォルダーの `session.log`、GPU の型番、画面の接続情報を提供してください。

## 技術実装

### 画面取得と画像処理

[画面取得モジュール](vision.py)は DXGI／DXcam でゲーム領域の新しいフレームを取得し、取得前後にフォーカス、位置、サイズ、遮蔽を確認します。制御ループの目標は 60 FPS ですが、実際の速度はゲームの新規フレーム、認識処理、システムのスケジューリングに依存します。新しい画面がない場合、古い画面に基づいてジャンプしません。100ms 以上の取得間隔が生じた後は復帰フレームを破棄して認識器を初期化し、500ms 待っても新規フレームが得られなければ停止します。

[領域処理](priority.py)は 960×540 を認識基準とし、サンプリング領域を先に切り出して同じ倍率で縮小します。切り出し境界は入力・出力解像度の整数比に合わせ、元のサンプリング位置を保ちながら不要な画素の処理を減らします。

### 縄の認識と曲線推定

[追跡器](candidate_tracker.py)は横方向の五つの区間から計 100 列をサンプリングします。HSV 色範囲で青紫・金・ピンク・明るい白の候補を抽出し、フレーム間の動きと細線の明暗特徴で背景を除外します。複数区間の点群から二次曲線を求め、曲線上の支持率と区間間の分布で評価します。信頼度の高い観測は縄の色の基準も更新します。

選ばれた曲線から、プレイヤー位置に対する縄の高さ、可視部分の支持率、主な色、移動方向を求めます。中央がキャラクターや小物で隠れても、両側の見える断片が曲線推定を制約します。証拠不足の場合は再観測に必要な状態を保持し、固定周期でジャンプしません。

### ジャンプ判定と遮蔽からの復帰

[認識器](jump_detector.py)は接近、通過、離脱、低い縄の折り返しなどの画面状態で、同じ縄の通過を既に処理したか判断します。遮蔽後の再準備では連続した可視断片、左右の支持と高さの変化を確認し、同じ通過での重複入力を抑えます。

急変チェックは「最後の実際の観測時刻」と「最後に採用した位置の時刻」を区別します。部分的な支持しかない曲線が突然プレイヤーへ近づいても、保存位置が古くなったという理由だけでは採用しません。直近三つの観測が信頼できる連続した接近を示せば通常判定に戻れます。

### 入力・メニュー・続行

[制御モジュール](jump_rope_bot.py)はジャンプ候補の発生後に新しい画面を再取得し、プレイ中であること、プレイヤーが操作可能であること、ジャンプボタンが見えることを確認します。相対座標を画面座標へ変換し、Windows のマウス入力で左ボタンを 25ms 押すよう要求します。中断時にもボタンを解放します。実際の押下時間は診断に記録され、スケジューリングの影響を受ける場合があります。

メニュー認識はボタン位置、水色のカプセル形外枠、白い縁とページ配色を使い、内部文字を比較しません。複数フレームで確認し、同一ページの再試行回数を制限します。ゲーム HUD を確認すると、そのプレイ中のメニュー操作を終了します。[セッション制御](batch_session.py)は終了と安定した結果画面の両方を確認してから続行し、目標回数で停止します。通常の画面と入力だけを使い、ゲームのプロセスメモリ、セーブやゲームファイルを読み取ったり変更したりしません。

## 不具合報告と開発者モード

続行やジャンプの異常などは [GitHub Issues](https://github.com/harrykuang-dev/Hololive-Dreams-Jump-Rope-Auto/issues) へ報告してください。

問題を再現する前に開発者モードを有効にすると、診断画像、フレームごとの認識記録、入力時刻と処理時間をローカルに保存します。自動アップロードは行いません。有効化すると処理負荷が増加します。

右の `?` から診断フォルダーの表示とオープンができます。

```text
%LOCALAPPDATA%\HololiveJumpRopeAuto\sessions\
```

実行ごとに日時付きフォルダーを作り、各回終了後に `round-番号` 内へ `diagnostics.zip` を生成します。報告にはアプリのバージョン、ゲーム言語／キャラクター、解像度、Windows の表示倍率、症状と該当回の ZIP を添えてください。
