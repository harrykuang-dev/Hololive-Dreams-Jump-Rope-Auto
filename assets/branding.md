# Hopping Rope Logo

按用户指定，前端Logo和Windows图标使用游戏的Hopping Rope标识。

- 原图：`hopping-rope-logo.png`，1024×512 RGBA，保留原始透明通道。
- 来源：本机已安装游戏快取的`img_mg_logo_jumprope`纹理。
- 原始缓存MD5：`a7f4dfc0b442f056727e098e709426f0`，156,092字节。
- 图标：`tools/make_icon.py`按比例缩放到透明方形画布，生成16–256像素ICO。

原图只用于前端显示和应用图标，不参与画面识别或V27起跳控制。
