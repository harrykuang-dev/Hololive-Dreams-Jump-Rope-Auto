# Hololive Dreams Auto Jump Rope

[English](README.md) · [繁體中文](README.zh-TW.md) · [日本語](README.ja.md) · [한국어](README.ko.md) · [Indonesian](README.id.md) · [简体中文](README.zh-CN.md)

Windows 버전 《hololive Dreams》의 자동 줄넘기 프로그램입니다. 게임 화면에서 줄의 위치를 인식하고 일반 마우스 입력으로 점프하며, 결과 화면을 확인한 뒤 다음 라운드를 시작합니다.

## 다운로드

[Releases](https://github.com/harrykuang-dev/Hololive-Dreams-Jump-Rope-Auto/releases/latest)에서 **1.3.2** Windows x64 전체 `.7z` 패키지를 다운로드하고 압축을 푸세요. TensorRT 10.13과 DirectML을 포함하며, 호환되는 NVIDIA 환경에서는 TensorRT FP16을, 그 외 지원 GPU에서는 DirectML을 자동으로 사용합니다.

EXE, `_internal/`, `accelerators/`를 함께 보관하세요. 실행 시 PyTorch를 사용하지 않습니다. TensorRT를 처음 시작하면 게임 조작 전에 로컬 GPU용 엔진을 생성하고 캐시하므로 몇 분 정도 걸릴 수 있습니다.

이전 소스 코드와 MIT 라이선스는 [archive/v1.2.1](archive/v1.2.1/)에 보관되어 있습니다.

## 기능

- 중지 점수는 제한 없음 또는 1–999로 설정합니다. HUD 점수 도달을 확인하면 점프를 멈추고 결과 화면을 기다린 뒤 설정한 라운드 수까지 계속합니다.
- 줄의 움직임을 추적하고 점프 시점을 자동으로 판단합니다.
- 점프 시점을 −40~+40 ms 범위에서 연속 조절합니다. 회전과 바닥 쓸기 모두에 적용되며 중앙은 기본값입니다. 음수는 빠르게, 양수는 늦게 동작합니다. 0 또는 레일 중앙을 클릭하면 초기화됩니다.
- 시작 및 결과 메뉴를 인식하고 라운드가 끝나면 다음 라운드를 진행합니다.
- 번체 중국어, 간체 중국어, 영어, 일본어, 한국어, 인도네시아어를 지원합니다. 프로그램 언어를 변경해도 게임 설정은 바뀌지 않습니다.
- 목표 라운드에 도달하면 정지합니다.
- 기본 단축키는 시작 F8, 정지 F9입니다. 설정란을 클릭하고 키 또는 키 조합을 누르면 변경할 수 있습니다. 시작과 정지 단축키는 서로 달라야 합니다.
- 실행 기록과 선택적으로 사용하는 로컬 개발자 진단 모드를 제공합니다.

## 사용 방법

1. 게임에서 줄넘기 시작 또는 결과 화면을 엽니다.
2. EXE를 실행하고 언어/Language에서 프로그램 언어를 선택합니다.
3. 목표를 1–999라운드로 설정합니다. 기본값은 1입니다. 단축키를 바꾸려면 설정란을 클릭하고 원하는 키를 누릅니다.
4. 시작 버튼이나 시작 단축키를 누릅니다. 프로그램이 게임을 전면으로 전환하려고 시도합니다. 게임 전체가 주 모니터 안에 보이도록 하고 다른 창으로 가리지 마세요. 어두운 색상, 짧은 머리, 장식과 액세서리가 적은 캐릭터를 권장합니다. 예: **쥬후테이 라덴(기본 의상)**과 픽셀 선글라스(pixel sunglasses).
5. 정지 단축키 또는 정지 버튼으로 멈춥니다. 게임이 포커스를 잃으면 실행당 최대 1회까지 게임을 전경으로 복원합니다. 다른 프로그램으로 전환하기 전에 먼저 정지하세요.

## 사용 조건과 제한

GPU 추론만 사용합니다. 전체 패키지에는 TensorRT 10.13과 ONNX Runtime DirectML이 포함됩니다. 호환 NVIDIA 환경에서는 TensorRT FP16을 자동 선택하고, 그 외에는 지원되는 DirectX 12 하드웨어 GPU에서 DirectML을 실행합니다.

Windows 10／11 x64와 Windows 게임 클라이언트가 필요합니다. 게임 클라이언트 영역을 16:9로 유지하고 실행 중 최소화하거나 가리거나 이동하지 마세요.

게임이 안정적으로 60 FPS를 유지하는 범위에서 그래픽 설정을 최대한 높이세요.

화면의 점프 입력은 조작 횟수입니다. 실제 점수는 게임 결과 화면에서 확인하세요. 캐릭터 색상, 애니메이션, 해상도, PC 성능과 게임 업데이트가 인식에 영향을 줄 수 있습니다. 문제가 생기면 정지하고 진단 자료를 제공하세요.

## 기술 구현

전체 게임 클라이언트 화면을 비율을 유지한 letterbox 방식으로 640×640으로 변환합니다. YOLO26n Detect 모델 하나가 보이는 줄의 경계 상자와 플레이어의 삼각형 표시를 인식합니다. 같은 학습 가중치를 TensorRT 10.13 FP16 또는 ONNX Runtime DirectML로 하드웨어 GPU에서 실행하며 CPU 모델 추론은 사용하지 않습니다.

[시계열 제어기](controller/policy.py)는 연속 경계 상자, 움직임, 실제 프레임 간격과 형태별 기준 동작으로 다음 줄 통과를 추정합니다. 플레이어 표시와 실제 입력 이력으로 공중·착지 상태를 확인합니다. 부분 상자는 부분 증거로만 사용하며 가려진 줄을 채우지 않습니다. 안정적인 단기 예약만 제한된 가림 동안 유지하며 원형 동작은 추정 속도에 따라 시점을 조정합니다.

[슬라이더](timing_control.py)는 원형 및 바닥 쓸기 동작의 입력 구간과 예약을 −40~+40 ms 범위에서 연속 조정합니다. 중앙이 기본값이며 0 또는 트랙 중앙을 클릭하면 복원됩니다.

[중지 점수](score_limit.py)는 같은 캡처 화면의 HUD 숫자를 읽고 신뢰할 수 있는 반복 판독과 점수 증가 검사를 통해 도달을 확인합니다. 도달하면 예약과 입력을 해제하고 정상 결과 화면을 기다립니다. 무제한 모드에서는 점수를 인식하지 않습니다.

[제어 루프](jump_rope_bot.py)는 DXGI 캡처 하나와 입력 소유자 하나를 사용합니다. 독립적인 중단 가능 타이머가 목표 25 ms 후 입력을 해제하고 그동안 계속 관찰합니다. 누르기 직전에 전경, 크기, 중지 요청과 원본 화면 식별 번호를 확인합니다. 통과 시점의 허용 범위와 가림 예측의 시간 제한은 유지합니다. 시작·결과 메뉴는 문자에 의존하지 않는 형태와 색상으로 판정합니다.

## 문제 보고와 개발자 모드

다음 라운드 진행 실패, 점프 이상 등은 [GitHub Issues](https://github.com/harrykuang-dev/Hololive-Dreams-Jump-Rope-Auto/issues)에 보고하세요.

문제를 재현하기 전에 개발자 모드를 켜세요. 진단 이미지, 프레임별 인식 기록, 입력 시각과 처리 시간을 로컬에 저장하며 자동 업로드하지 않습니다. 켜면 처리 부하가 증가합니다.

오른쪽 `?`를 누르면 진단 폴더를 확인하고 열 수 있습니다.

```text
%LOCALAPPDATA%\HololiveJumpRopeAuto\sessions\
```

실행마다 시간으로 이름을 지정한 폴더를 만들고, 모든 라운드의 텍스트 진단을 `diagnostics.json` 하나에 모아 진단 이미지와 함께 저장합니다. 실행 종료 시 이 JSON과 보관된 이미지를 포함한 `diagnostics.zip`을 생성합니다. 화면 캡처 전에 초기화가 실패한 경우에도 저장합니다.

GPU·드라이버 정보, 실제 추론 백엔드와 폴백 오류, 캡처·추론 시간, 인식 및 점프 판단, 입력 시각, 포커스를 가져간 창 제목과 프로세스 이름, 정지 이유를 기록합니다. 문제를 보고할 때 이번 실행의 ZIP과 문제 설명을 첨부하세요.
