# Hololive Dreams Jump Rope Auto

Windows 跳繩自動化實驗版本。目標為單局 100 下，目前尚未達成或驗證。

## 控制方式

只在畫面同時存在分數、剩餘生命及 Jump 按鈕時允許視覺偵測器送出單次跳躍。
連點模式、固定加速曲線及失去視覺訊號後的自動週期補跳均已移除。
開始辨識本局後，生命歸零或無法確認遊玩畫面即停止；不會自動點擊結算、下一步或重新開局。
遊戲失去焦點或按 F9 也會停止。

起跳偵測改為擬合移動繩子的完整曲線，觀察繩子由上方降至前方最低處，再開始回升的視覺序列；不根據前次間隔預定下一次點擊。
目前仍會漏判遮擋、變色與反轉，不能視為已完成的 100 下方案。預設只觀察，不送出輸入。

## 執行

需要 Windows 與 Python 3.10 以上。

    python -m pip install -r requirements.txt
    python main_ui.py

手動進入一局後啟動；可在遊戲中按 F9 停止。GUI 的 F8 只在程式介面有焦點時有效。

    python jump_rope_bot.py --duration 120

上面的指令只觀察。若要自行測試尚未驗證的輸入，使用 `--play`，或在 GUI 勾選「啟用實驗性單局輸入」。只執行本局，不自動下一步。

    python jump_rope_bot.py --play --duration 120

點擊次數只代表送出輸入，不能作為遊戲分數。100 下必須由單局結果畫面與對應紀錄驗證。

## 測試

    python -m pytest -q

離線回放工具不會操作遊戲；debug 目錄存放本地分析影格，不納入 Git。

    python tools/replay_visual_pass.py "錄影.mp4"
    python tools/scan_round_gate.py "錄影.mp4"

上述工具目前使用提供影片的 1920×1080 畫面與客戶區裁切座標，不能直接套用其他錄影。
