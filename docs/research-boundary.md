# 研究与成品边界

用户要求最终成品仍以输入画面进行跳绳，不能包含解包内容。独立研究环境、下载缓存、解包资源及相关工具仅保存在本机忽略目录，不属于应用依赖、输入或发布资产。

运行时继续只读取实时窗口画面，从当前可见绳形产生起跳事件。不读取游戏内存、安装文件、动画曲线、内部碰撞参数或研究目录，不用解包图片作为识别模板，也不根据内部动画预定起跳时刻。失去有效画面时停止。

构建后，`tools/build_release.py` 自动调用 `tools/verify_release_bundle.py`。验证器比较八个冻结源码模块及六项既有资源，拒绝归档实验模块、研究工具依赖、本机研究目录、常见游戏资源文件及额外 `assets/` 文件。输出位于 `dist/release-verification.json`。

这一检查是模块和文件边界检查，不是对每个依赖字节的语义审查。新增依赖或资产时仍需核对来源；不要通过重命名游戏资源规避检查。既有菜单模板来自画面，允许的资源为图标、三个开局菜单截图模板及许可证文件。

正常游玩与测试不补充或修改能量，不点击能量恢复、BOOST、MODE、购买或道具入口。零能量不是拒绝开局的条件。录影、输入日志及研究文件不自动上传。
