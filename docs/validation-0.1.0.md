# 0.1.0 发布验收

本版是实验版本，未实现七局稳定 100。六轮完整优化中，v18b 显著改善过基准；其后 v19b、v20b、v21b 三轮均未达到事先固定的显著进步标准，按用户约定停止调参。各轮真实分数、未计入的中断及判定方法见 [优化记录](optimization-0.1.0.md)。

发布默认恢复 v18b 绳形识别，保留加载宣传页防误认、初始 HUD 有界新帧等待、外部停止、六语言 GUI 和本机诊断。归档候选不进入程序。v18b 最佳基准七局为 110 / 87 / 84 / 108 / 112 / 78 / 91；该成绩不冒充最终 GUI EXE 的成绩。

## 检查结果

196 项非界面测试通过：192 项验证发布代码，4 项验证只供离线研究的归档候选。六项界面测试通过，覆盖六种语言、100/125/150/200% DPI 下的控件布局、设置锁定、重复开始防护、计数重置、快捷键捕获和关闭等待。界面模拟测试不证明实战成绩。

最终 EXE 已由 Computer Use 实际打开，文字、按钮、日志和页脚可见；[初始界面预览](evidence/0.1.0/interface.jpg) 来自实际打包程序。

最终 GUI 完整七局真实分数：**85 / 85 / 89 / 103 / 87 / 86 / 83**。1 局达到 100，最低 83，中位数 86，实际捕获 54.83–55.46 FPS。七局正常结束、编码完整、MP4/JSON 帧数一致、结果后零起跳、开局后零菜单输入。

[完成界面](evidence/0.1.0/completed-interface.jpg) 显示 7/7、644 次输入，设置解锁、停止按钮禁用；第七局后没有导航或第八局。644 是输入总数，不是游戏分数。[结算图](evidence/0.1.0/seven-results.jpg) / [成绩审计](evidence/0.1.0/release-audit.json) 可核对。会话 `20261001-133809-130550` 的 EXE 哈希与发布程序一致；这是集成验收，不再调参。

## 边界与证据

零能量可以正常游玩；没有调整能量、恢复道具、BOOST、MODE、购买或道具入口。所有起跳由当前绳形授权，没有固定周期、预定加速或遮挡期间的补跳。F9、外部停止、失焦、真实遮挡和录像硬错误仍停止。

每局 MP4/JSON 的逐帧映射和已写帧数核对，结算后零起跳、开局后零菜单输入。审计检查 MP4 元数据帧数及最后一帧解码，范围不是全文件逐帧解码；分数另由结算帧人工核对，不以输入次数或历史最佳 132 代替。

完整成绩审计为去除用户路径的汇总；原始录像、事件和运行日志只保存在本机，没有自动上传。此前 v15 单局 102 的原始交付与旧录像均保留。游戏菜单仍仅按繁體中文界面实际验证。
