# 版本迭代記錄

目前正式版本為 **v1.0**。下列舊版本、研究分支及測試候選均為 **已迭代**，只記錄開發經過，不提供舊執行入口或測試素材。原型使用 P1–P6，單局測試版使用 S1–S15，批量及後續開發版使用 B 編號，測試候選使用 T 編號，各系列的版本名稱互不重複。原型與測試候選採用補充編號，便於區分歷史階段；v 前綴僅用於正式發布版。

成績只採用已核對的遊戲結算分數；按鍵次數、離線候選數與未結算中途分數不當作成績。不同批次的角色、畫面與測試條件不一定相同，單局高分和小樣本平均不構成穩定提升的證明。未保存完整獨立變更或成績的版本保留缺項標記。

## v1.0：目前正式版

- 以 B27 起跳邏輯整理為正式程式，保留 25ms 輸入與 960×540 識別配置。
- 完成六語言桌面介面、可調局數、可自訂開始／停止快捷鍵與執行記錄；移除只觀察介面及固定 F9 說明，介面顯示正式版本號 1.0。
- 開局按鈕改依位置、顏色和外形識別，不依按鈕文字，支援遊戲多語言。
- 開發者模式預設關閉；啟用時記錄逐幀觀察、按鍵時序、事件與失誤截圖，產生便於 Issue 回報的壓縮包。正式診斷不包含影片。
- 更新標誌與工作列圖示，加入角色外觀及穩定 60 幀下提高遊戲畫面設定的建議。
- 正式發布頁和一般使用說明只呈現 v1.0；歷史試驗內容集中於本文件。測試影片、解包研究工具與舊候選不隨正式成品提供。
