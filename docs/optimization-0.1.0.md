# 0.1.0 优化与实战记录

目标：七局都达到 100，或连续三轮完整实战优化没有显著进步后停止调参，完成图形界面和 0.1.0 发布。

每轮候选先通过旧录像时机回归和安全测试，再运行七局。分数人工核对录像结算，不以输入次数、历史最佳或离线候选数替代。零能量正常游玩；不使用能量恢复、BOOST、MODE、购买或道具。

为避免单局最高分掩盖稳定性，本次把“显著进步”定义为对比最佳已验证基准，满足以下任一项：达标局数增加至少 2；中位数增加至少 10 且最低分不退步；最低分增加至少 10 且中位数不退步。显著进步重置连续无进步计数。七局全部达到 100 后，再复测七局验证重复性。它仍不能保证未来每局成绩。

## 第一轮 v16

v15 第三局第一次失误：70.877 秒的 .009 小幅回升让 70.9465 秒过早触发；真实第二个高点后应在约 71.237 秒触发。密集捕获（相邻有效观测小于 40 ms）要求至少 .015 回升，保留较低帧率录像的 .008 回升证据。判断依赖当前可见绳形，不按周期补跳。

统一增加回升阈值及统一推迟下降阈值的离线实验会丢失既有正确窗口，已放弃，未算作完整优化轮次。

完整实战证据：`batch-test-20261001-004040-824275`。七局均正常结束、编码完整、MP4/JSON 帧数一致、结果后零起跳、开局后零菜单动作。第三局最高 112，但达标局数和最低分不变，中位数下降，没有显著进步。最高分不作为停止计数重置依据。169 项测试通过后构建。

此前 `batch-test-20261001-003651-561843` 首局 90，第二局加载时失焦停止，未满七局，不计优化轮次。中断记录保留；用户随后确认误按停止并要求继续。

## 第四轮 v19b

v18b 第一局第一个失误：远侧绳形最后可靠可见于 127.8926 秒，被道具遮挡约 336 ms 后重新出现于 128.2285 秒，原有五次间隔观测的预算在重新出现前清除起跳授权。仅普通高绳可短暂保留该授权到 360 ms，仍需要当前可见绳形、对比度及方向证据；遮挡期间不输入，长遮挡仍取消授权。保留 v18b 的模式与噪声修正。

v19 原构建 SHA-256：`33f40e92d529e98bde55a3883f869b8a05b80e750eb23b22fa92a84e86981d05`。两次未完成批次分别为 `batch-test-20261001-120632-012967`（第一局，初始 HUD 静止、零输入）及 `batch-test-20261001-121519-149114`（四局完成，第五局加载页、零输入）。均因 DXGI 没有新画面停止，不计完整优化轮次。第二次实际完成前三局 72 / 106 / 93，不能以部分成绩替代七局。

第二次的宣传提示页短暂符合旧 HUD 颜色计数，被误当实战。增加蓝色 Jump 按钮背景的像素检查，并保留该加载页为反例。真正初始 HUD 在尚无可靠绳形、起跳候选或输入时，允许最多 3 秒静止等待；不处理缓存帧。一旦出现可靠绳形，实战新帧缺失仍停止。F9、失焦、真实遮挡检查始终有效。相关控制与画面回归通过后构建 v19b。

v19b SHA-256：`440c593802b67c2e18f8920a7c2708df3b3905140dd5f75e403d2094b998de1f`，前缀 `batch-test-20261001-122927-857813`。

完整七局真实分数 100 / 84 / 78 / 81 / 89 / 86 / 60。七局正常结束、编码完整、MP4/JSON 帧数一致、结果后零起跳、开局后零菜单输入，第七局后不再导航。相比 v18b，没有显著进步；连续无显著进步为 1。开局问题修复不改变成绩判定。

## 第五轮 v20b

## 第六轮 v21b：达到停止条件

v21 候选：v18b 第三局 39.2043 秒的部分道具拟合先被拒绝，下一帧仅因上次接受样本已超过 40 ms 而重新接受，39.238 秒过早触发。只对已经拒绝、仍持续的远侧到近脚部大跳位保留最多 80 ms 拒绝窗口，强当前绳形仍可接受。整段原始量测回放保留 39.3723 秒真实接近。全局把窗口改成 80 ms 会破坏八项旧回归，已放弃，未计优化轮次。针对性修改保持旧回归通过；同一压缩视频 A/B 候选相同，不视为实战提升。

v19b 第七局又出现同类错误：63.3756 秒拒绝的部分道具拟合在 63.4114 秒提前触发，导致真实接近 63.6765 秒前已经起跳。v21b 的保留窗口覆盖整个蓝绳触发区，仍只适用于已拒绝的持续部分跳位；原有快速蓝绳测试保持通过。整段原始量测回放只保留 63.6765 秒，同像素压缩视频 A/B 仍相同，不代替实战成绩。

首次 GUI 会话 `20261001-130958-875815` 在首帧前被电脑操作提示层阻挡 20 秒，零输入停止，不计优化轮次。仅首次取帧前的有界等待改为最多 60 秒且不超过开局超时；取得首帧后出现任何提示层仍立即停止。196 项非界面及六项界面测试通过后重建，候选 SHA-256：`f1a64634f0fa70b6dbf57cbf2c0fea353f9aa09c5e728a06d3c0cdbcc3d8d00c`。第二次 `20261001-131403-681301` 提示层超过 60 秒仍零输入停止；第三次启动后释放 Computer Use JavaScript 会话，继续按日志验证。未完成的尝试均保留、不计七局成绩。

第三次完整 GUI 会话 `20261001-131611-073716` 真实分数 **100 / 79 / 98 / 76 / 97 / 89 / 55**。七局全部正常结束、编码完整、MP4/JSON 帧数一致、结果后零起跳、开局后零菜单输入；界面显示完成 7/7、总输入 626，设置解锁、停止按钮禁用，第七局后未导航。输入 626 不是分数。相比 v18b 的达标局数、最低和中位数均未改善；连续无显著进步达到三轮，**停止调参**，没有实现七局稳定 100。
